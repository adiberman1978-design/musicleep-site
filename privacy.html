Musicleep privacy policy

Musicleep is a personal tool used only by its owner, with the owner's own Google account and YouTube channel. It has no other users.

What it accesses

With the owner's consent, Musicleep uses the YouTube Data API to upload the owner's videos to the owner's channel and to set their title, description, tags, thumbnail, captions and visibility. It reads back only the status of those videos and the name of the channel.

What it stores

The sign-in token is stored only on the owner's computer, encrypted for the owner's Windows account. Musicleep has no server, and it does not collect, sell or share data about anyone.

Limited use

Musicleep's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also relies on YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The owner can remove Musicleep's access at any time from Google account permissions.
